Developer account:
worldsundersiege@gmail.com

WHAT IT DOES
- Lets this email open index.html even while onboarding_complete is false.
- Shows a Developer Mode shortcut bar on the Main Hub.
- Provides shortcuts to:
  - Start Onboarding
  - Main Hub
  - Deck Builder
  - Open Packs

IMPORTANT
This is a client-side development convenience, not a security permission system.
It does not grant database admin access and does not use a Supabase secret key.

UPLOAD/REPLACE
- auth-guard.js
- index.html
- hub.js
- hub.css

The other included files are unchanged dependencies.
