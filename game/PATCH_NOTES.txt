Worlds Under Siege — Simultaneous Trigger Ordering Patch v9

Focus: deterministic ordering for multiple triggers caused by one event.

Changes:
- Trigger conditions are evaluated first, before any matching trigger enters the stack.
- Matching triggers are collected into one simultaneous-trigger batch.
- Added APNAP ordering:
  Active-player triggers enter first, then non-active-player triggers.
- Registration order is preserved within each owner group.
- Unowned/global triggers enter after player-owned triggers.
- Only one priority window opens after the whole trigger batch is stacked.
- Prevents later triggers from resetting priority opened by earlier triggers.
- Added openPriorityForQueuedTriggers().
- queueTriggeredAbility() now supports openPriority:false for batch placement.
- Trigger stack entries record originalEventId for debugging.
- Priority text reports how many simultaneous triggers entered the stack.
- Updated cache versions for events.js and priority.js.
- All JavaScript files passed `node --check`.
