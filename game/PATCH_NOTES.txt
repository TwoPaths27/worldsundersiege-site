Worlds Under Siege — Interactive Trigger Choices Patch v12

This consolidation pass follows the fixed stack rule:
LAST ENTERED / LAST PLAYED IS ALWAYS FIRST TO RESOLVE.
Players cannot reorder Action or effect stacks.

STACK ORDER
- Removed APNAP/player-controlled ordering assumptions.
- Simultaneous triggers preserve deterministic registration/discovery order.
- Triggers enter in that order.
- The shared stack remains strict LIFO, so the final entry resolves first.
- No reorder controls or reorder APIs were added.

OPTIONAL TRIGGERS
- Added visible Yes and No controls inside the left priority panel.
- Optional triggers pause only when they reach the top of the stack.
- Yes continues toward resolution.
- No resolves the trigger as optional-trigger-declined without executing it.
- Escape also declines an optional trigger.
- Priority passing is hidden while a required trigger choice is pending.

TRIGGER TARGETING
- Triggered abilities that require a target pause when they reach the top.
- If exactly one legal target exists, it is selected automatically.
- If multiple legal targets exist, legal battlefield Units are highlighted.
- Clicking a highlighted Unit selects it and resumes resolution.
- If no legal target remains, normal resolution validation causes the trigger
  to fizzle rather than changing stack order.

SAFETY AND STATE
- Pending trigger choices are tied to a specific stack ID.
- Choice state is cleared when the stack entry leaves.
- Match selection resets clear pending trigger choices.
- Trigger entries remain on the stack during choices; they are never moved.
- Added safe UI bindings and target-highlight styling.
