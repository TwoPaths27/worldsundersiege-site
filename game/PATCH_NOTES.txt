Worlds Under Siege — Trigger Lifecycle Patch v10

Focus: automatic trigger registration and cleanup as units enter and leave play.

Changes:
- Events now snapshot matching trigger registrations when the event is created.
- A source can still produce its own death/leave-play trigger even when it is
  unregistered immediately after leaving the battlefield.
- destroyUnit() now emits:
    1. unitLeavingPlay
    2. unitDestroyed
    3. unitLeftPlay
- destroyUnit() unregisters all triggers belonging to the removed unit.
- Recruited units register their triggers before enter-play events are emitted.
- Added unitEnteredPlay while preserving the existing unitSummoned event.
- Added initialBattlefieldReady after starting units register their triggers.
- Updated cache versions for events.js, rules.js, battlefield.js, and match.js.
- All included JavaScript files passed `node --check`.

Replace all included files and hard-refresh with Ctrl+Shift+R.
