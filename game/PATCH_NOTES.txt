Worlds Under Siege — Trigger Stack Patch v8

Focus: triggered abilities now use the same stack and priority system as Actions.

Changes:
- Trigger listeners no longer execute abilities immediately.
- Added createTriggeredAbilityStackEntry().
- Added queueTriggeredAbility().
- Triggered abilities are added to GameState.actionStack.
- Players receive a priority window before a triggered ability resolves.
- Triggers created during resolution wait safely above the current stack item.
- Added resolveStackEntry() to route Action and Trigger entries correctly.
- Trigger entries do not increase discardCount or move to the discard pile.
- triggerResolved is emitted only after the triggered ability actually resolves.
- Stack rendering now tolerates entries without an Action card.
- Updated cache versions for events.js and priority.js.
- All JavaScript files passed `node --check`.

This patch changes trigger timing infrastructure but does not add a specific new
card trigger. Existing triggered definitions will now use priority automatically.

Replace all included files and hard-refresh with Ctrl+Shift+R.
