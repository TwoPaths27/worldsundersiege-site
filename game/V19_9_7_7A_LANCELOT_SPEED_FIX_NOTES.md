# V19.9.7.7a — Sir Lancelot Speed Hotfix

- Face-up recruitment now counts as a reveal for Sir Lancelot's effect.
- Turning him face-up from Conceal still triggers the same effect.
- The +3 SPD modifier is applied only once per turn.
- `remainingSpeed` is synchronized immediately after the modifier is applied, preserving movement already spent.
- The effect still expires at the end of the turn in which he was revealed.
