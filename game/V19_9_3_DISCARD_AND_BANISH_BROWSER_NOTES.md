# Worlds Under Siege V19.9.3 — Discard & Banish Browser

## Implemented

- Discard and Banish piles are public for both players.
- Clicking any Discard or Banish pile opens a read-only card browser.
- The browser uses the same visual card language as the Hand.
- Opening the browser hides the Hand dock.
- The title changes to `Discard` or `Banish` and identifies the pile owner.
- Card counts are displayed live from the authoritative Zone Engine.
- Cards are shown newest-first so the top card of the pile appears first.
- Hover, focus, or click updates the existing Card Preview panel.
- Added a top-right X close button.
- Clicking the backdrop or pressing Escape also closes the browser.
- Closing restores the Hand to its previous visibility state and returns focus to the pile button.
- Empty public zones show an explicit empty-state message.
- Added responsive and reduced-motion styling.
