# V19.9.6.6a — Mount Prompt UX Fix

- A legal Mount glows blue after a friendly face-up Character is selected.
- Hovering or focusing the Mount changes the glow to gold and reveals a centered MOUNT? button.
- The prompt is a real button with a forced top-level stacking order.
- Clicking the Mount tile no longer replaces the selected Character with the Mount's actions.
- Clicking the MOUNT? button mounts the selected Character and stops the tile click from propagating.
- Keyboard focus and Enter/Space activation remain supported.
