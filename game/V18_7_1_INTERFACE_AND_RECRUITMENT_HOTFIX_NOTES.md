# Worlds Under Siege v18.7.1 — Interface and Recruitment Hotfix

## Fixed

- Advanced Stops now opens inward from the left sidebar and stays inside the viewport.
- Character recruitment can no longer remain locked when a Web Animation rejects, is cancelled, or never resolves. Recruitment animations are now presentation-only and use a guarded timeout before gameplay continues.
- Enemy and player stronghold lanes are explicitly centered to the seven-column battlefield width.

- `game.css`
- `battlefield.js`
