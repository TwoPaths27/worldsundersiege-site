# V19.9.7.6 — Mobile UI Foundation

Desktop behavior is unchanged. The mobile presentation layer activates only at 900px or below or on coarse-pointer devices.

Implemented:
- One-finger board panning.
- Two-finger pinch zoom from 45% to 280%.
- Center Board control and double-tap/double-click reset.
- Mobile chat drawer with unread-message badge.
- Game Log removed from the mobile presentation.
- Contextual Expand button over selected battlefield Units.
- Full-card art modal for battlefield Units.
- Mobile hand horizontal swiping and snap behavior.
- Larger touch hit areas and touch-friendly dialogs.
- Safe-area support for phones with notches and home indicators.
- Desktop opt-out query for testing: `?desktop=1`.
