# v18.8.1 — Counter Window UI Simplification

## Changes

- Removed the persistent **Action Timing** heading.
- Removed the always-visible AUTO/FULL priority row.
- Moved Full Control into the developer gear menu.
- Hidden the priority panel during normal gameplay.
- The panel now appears only when the player has a response/decision.
- PASS appears only when the local player can actually pass priority.
- Counter windows display a short reason such as attack, targeting, Action, or card entry.
- Game Chat receives the sidebar space previously reserved for priority controls.

- `index.html`
- `priority.js`
