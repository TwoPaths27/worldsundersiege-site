WORLDS UNDER SIEGE — SLOW FOG BACKGROUND

ADDED
- Three slow CSS-generated fog layers.
- Different movement speeds and directions create depth.
- Fog remains behind all words, cards, panels, buttons, and dialogs.
- Fog never blocks mouse or touch input.
- No image or video file is required.
- Reduced-motion accessibility support is included.
- Mobile opacity is reduced for readability and performance.

FILES ADDED
- fog.css
- fog.js

ALL HTML PAGES WERE UPDATED
Each page now loads fog.css and fog.js.

CUSTOMIZING THE STRENGTH
Open fog.css and change:

#wus-fog-layer{
  opacity:.78;
}

Lower values make the fog subtler.
Higher values make it stronger.
